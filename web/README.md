# randprotocol.org/clients

Source of truth for the wallets download page at https://randprotocol.org/clients. The site
itself lives in the sibling repository `../randprotocol.org` (Astro + Tailwind v4).

To publish a change:

```bash
cp web/clients.astro            ../randprotocol.org/src/pages/clients.astro
cp web/public/clients/icon-256.png ../randprotocol.org/public/clients/icon-256.png
cd ../randprotocol.org && npm run build      # dist/clients/index.html
# then deploy per that repo's DEPLOY.md (rsync of dist/ to the droplet)
```

The site's header (`src/components/Header.astro`) carries a "Wallets" nav link to `/clients`,
and `/download` links here from its "Wallet and prover" card; both were added on 2026-09-13.

Store links: the `links` constant at the top of `clients.astro` is `null` per platform until
each listing is live; set the URL and the card switches from "Coming to the store" to a button.
The icon is generated by `design/make-icons.py` (`design/out/icon-256.png`).
