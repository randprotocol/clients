## First launch

Nothing here is signed with a paid developer certificate yet.

- **macOS**: System Settings → Privacy & Security → **Open Anyway**, or `xattr -dr com.apple.quarantine "/Applications/Rand Wallet.app"`.
- **Windows**: SmartScreen → **More info → Run anyway**.
- **Linux AppImage**: `chmod +x` it first.
- **Android**: signed with this project's upload key, certificate SHA-256 `75:22:2E:BF:22:D3:95:80:A5:11:2A:AC:B7:EC:2E:03:93:91:07:77:96:E0:45:1D:7B:CF:E3:7E:FA:06:53:52`.

A device that can make a proof (the desktop app, about 8 GiB) makes it. One that cannot — a browser, most phones — now uses **the RandProtocol prover** by default (https://prover.randprotocol.org, four machines run by the validators, no fee), after a one-time notice: like any prover it is sent the wallet's viewing key, so its operators can read the wallet's whole history, and it can never spend. Settings → Prover chooses your own prover instead (the desktop app's **Prove for my other devices**, or your own server), which is then always preferred, or none ([docs/prover.md](../prover.md)). Details, and how to build every client from source: the [README](https://github.com/randprotocol/clients#readme) and https://randprotocol.org/clients.

## Since v0.7.2

- **Twenty languages.** Hindi, Urdu, Pashto and Tamil join the sixteen of 0.7.2, on every client; Urdu and Pashto lay the wallet out right to left.
- **A browser always reaches the RandProtocol prover.** A transfer from the extension or the web wallet is proved by the RandProtocol prover unless Settings says otherwise, as 0.7.2 meant. A build made from a checkout that had built the wallet core once before could keep that older core, from before the prover was built in; such a build said "This device cannot prove the transfer" with nowhere to send the proof. Every build now makes the core again whenever its sources are newer.
- The review and proving screens say where the proof is made: "about 2 minutes on the prover" and "A prover will make the proof" when it goes to a prover, rather than "on this computer" and "The proof runs on this device".
- Pasting `https://prover.randprotocol.org` into Settings → Prover → Pairing link now says that these provers need no pairing because the wallet uses them by default, instead of "not a randprover: link".
- The proving ring spans 40 seconds, not 3 to 4.5 minutes.
- Terms of service ([TERMS.md](../../TERMS.md)), linked from every store listing.
