The first release with packages for every platform. Built for Rand testnet **chain 19**, which is chain 18's build (fullnode `v0.6.7`, constraint set 8) cut again with a new bridge section; the wallet core vendors fullnode `v0.6.6` (`d742a9b`), the first build of that constraint set. A wallet from this release refuses any other chain.

**Testnet software: not audited, not for real value.**

## First launch

Nothing here is signed with a paid developer certificate yet.

- **macOS**: System Settings → Privacy & Security → **Open Anyway**, or `xattr -dr com.apple.quarantine "/Applications/Rand Wallet.app"`.
- **Windows**: SmartScreen → **More info → Run anyway**.
- **Linux AppImage**: `chmod +x` it first.
- **Android**: signed with this project's upload key, certificate SHA-256 `75:22:2E:BF:22:D3:95:80:A5:11:2A:AC:B7:EC:2E:03:93:91:07:77:96:E0:45:1D:7B:CF:E3:7E:FA:06:53:52`.

The desktop app proves transfers on your computer (about 8 GiB of memory) and can prove for the browser extension on the same machine: Settings → **Prove for my other devices**. Details, and how to build every client from source: the [README](https://github.com/randprotocol/clients#readme) and https://randprotocol.org/clients.

## Since v0.6.5

- The wallet is aimed at chain 19: fullnode `v0.6.6`, constraint set 8, the bundle gas-limit pin and the envelope-format pin in every shell.
- **A first sync finishes on a rate-limited endpoint.** Every client looked for bridge deposits by opening every block, one request each — a hundred thousand requests on a chain that makes a block a second, against a public endpoint that allows about a hundred and then one a second. A new wallet never finished its first scan. The search now pages block headers (`rand_getBlocks`, 1024 a request) and opens only the blocks that carry a transaction, spends at most 96 requests a scan on it, and no longer fails the scan when the node will not answer; and a read refused with HTTP 429 is repeated after a wait instead of ending the scan. In the shared engine (extensions, desktop, web wallet), Android and iOS alike.
- Android targets API 36, pads its screens for edge-to-edge display, and the lock screen's Back handling moved to the back dispatcher.
- The submodule is fetched over https, so a clone needs no GitHub SSH key.
- A release pipeline: `scripts/release/`, `.github/workflows/release.yml`, `Jenkinsfile`.
