## First launch

Nothing here is signed with a paid developer certificate yet.

- **macOS**: System Settings → Privacy & Security → **Open Anyway**, or `xattr -dr com.apple.quarantine "/Applications/Rand Wallet.app"`.
- **Windows**: SmartScreen → **More info → Run anyway**.
- **Linux AppImage**: `chmod +x` it first.
- **Android**: signed with this project's upload key, certificate SHA-256 `75:22:2E:BF:22:D3:95:80:A5:11:2A:AC:B7:EC:2E:03:93:91:07:77:96:E0:45:1D:7B:CF:E3:7E:FA:06:53:52`.

A device that can make a proof (the desktop app, about 8 GiB) makes it. One that cannot — a browser, most phones — now uses **the RandProtocol prover** by default (https://prover.randprotocol.org, four machines run by the validators, no fee), after a one-time notice: like any prover it is sent the wallet's viewing key, so its operators can read the wallet's whole history, and it can never spend. Settings → Prover chooses your own prover instead (the desktop app's **Prove for my other devices**, or your own server), which is then always preferred, or none ([docs/prover.md](../prover.md)). Details, and how to build every client from source: the [README](https://github.com/randprotocol/clients#readme) and https://randprotocol.org/clients.

## Since v0.6.9

- **Swap, in the wallet.** The home screen's Faucet button is now Swap: trade RAND and tokens through the durian.market pools without leaving the wallet. Pick what you pay and what you receive; the wallet reads the pool from the chain and quotes the exact amount, the rate, the price impact and the 0.3% pool fee, then proves and sends the swap itself (the same program call durian.market asks for). The amount you receive is exact — if the pool moves before the swap lands, nothing is sent and you get a new quote. In the browser extensions, the desktop app and the web wallet; not yet in the phone apps. (The faucet is still one tap away from an empty activity list.)
- **Fullnode v0.7.0** inside: the audit v7 fixes, the incremental token root, and the RandProtocol provers' per-member keys. The proof programs are unchanged, so nothing about sending changes.
